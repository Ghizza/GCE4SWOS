# GCE4SWOS

### English

GCE4SWOS (Ghizza's Career Editor for Sensible World of Soccer) is a Python application for editing `.car` files (career save files) from Sensible World of Soccer.  
It allows you to modify the following:

**Managed team**
- Change kits (home and away)
- Set the budget to £100,000,000
- Reset transfers counters (buys and sales)

**Players**
- Change abilities (P, C, V, S, T, F, H)
- Change health status (injuries)
- Change disciplinary status (cards and suspensions)
- Change nationality
- Change role (G, RB, D, LB, RW, M, LW, A)
- Change value
- Change appearance (skin tone and hair)

The app is written in vibe coding, with some manual modifications.  
It is not compiled yet: Python must be installed on your operating system.  
Contributions to modify and expand it are welcome—indeed, essential.

#### Installing Python

To run GCE4SWOS, you need Python 3 installed on your system.  

- **Windows**: Download the official installer from [python.org/downloads](https://www.python.org/downloads/) and run it. **Important:** check the box **"Add Python to PATH"** during installation.  
- **macOS**: Download the installer from [python.org/downloads](https://www.python.org/downloads/) and run the `.pkg` file, or install via Homebrew with `brew install python`.  
- **Linux**: Most distributions include Python 3. Install or update it via your package manager (e.g., `sudo apt install python3` on Ubuntu/Debian).  

After installation, verify by opening a terminal or command prompt and running `python --version` (Windows) or `python3 --version` (macOS/Linux).

### Italiano

GCE4SWOS (Ghizza's Career Editor for Sensible World of Soccer) è un'applicazione Python per modificare i file `.car` (i salvataggi delle carriere) di Sensible World of Soccer.  
Consente di intervenire sui seguenti elementi:

**Squadra allenata**
- Modifica delle divise (casa e trasferta)
- Impostazione del budget a £100.000.000
- Azzeramento dei contatori di acquisti e cessioni

**Giocatori**
- Modifica delle abilità (P, C, V, S, T, F, H)
- Modifica dello stato di salute (infortuni)
- Modifica dello stato disciplinare (cartellini e squalifiche)
- Modifica della nazionalità
- Modifica del ruolo (G, RB, D, LB, RW, M, LW, A)
- Modifica del valore
- Modifica dell'aspetto (pelle e capelli)

L'app è sviluppata in vibe coding, con alcune modifiche manuali.  
Al momento non è compilata: è necessario avere Python installato sul proprio sistema operativo.  
I contributi per modificarla e ampliarla sono ben accetti, anzi indispensabili.

#### Installare Python

Per eseguire GCE4SWOS è necessario avere Python 3 installato sul proprio sistema.  

- **Windows**: Scarica l'installer ufficiale da [python.org/downloads](https://www.python.org/downloads/) ed eseguilo. **Importante:** durante l'installazione spunta la casella **"Add Python to PATH"**.  
- **macOS**: Scarica l'installer da [python.org/downloads](https://www.python.org/downloads/) ed esegui il file `.pkg`, oppure installa tramite Homebrew con `brew install python`.  
- **Linux**: La maggior parte delle distribuzioni include Python 3. Installalo o aggiornalo tramite il gestore pacchetti (ad esempio `sudo apt install python3` su Ubuntu/Debian).  

Dopo l'installazione, verifica aprendo un terminale o prompt dei comandi ed eseguendo `python --version` (Windows) oppure `python3 --version` (macOS/Linux).
